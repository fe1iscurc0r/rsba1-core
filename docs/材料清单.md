# RS-BA1 逆向项目 — 材料清单

## Phase 0: 原始文件

### 主程序 (raw/exe/)

| 文件 | 大小 | 描述 |
|------|------|------|
| `RemoteCtrl.exe` | 42.9 MB | RS-BA1 遥控主程序（PE32 GUI, stripped） |
| `CivCtrl.dll` | 148 KB | CI-V 通信控制 DLL（核心协议） |
| `HidCtrl.dll` | 16.5 KB | HID 通信 DLL |
| `UtyCtrl.dll` | 200 KB | Utility 控制 DLL |
| `RS-BA1V2Ck.dll` | 1.9 MB | 版本/许可证检查 DLL |
| `RemoteCtrl.dat` | 17 B | 数据文件（可能是运行时状态） |

### 机型配置 (raw/ini/)

24 个 INI 文件，对应各 Icom 机型（IC-705/7300/7610/9700 等）。包含 CI-V 地址、命令集、面板布局。

### 安装包原材料

原始安装包位于 `~/rsba1_work/icom RS-BA1 V2/RSBA1/`：
- `setup.exe` + `ISSetup.dll` — InstallShield 安装程序
- `data1.cab` + `data2.cab` — 安装数据包
- `Utility/setup.exe` + 对应 .cab — Utility 安装

升级包：
- `Update.exe` — V2.21 升级可执行文件（Rsba1_up_ver221 内）

## 外部资源

- `RS-BA1_manual_ENG.pdf` / `RS-BA1_manual_JPN.pdf` — 官方手册（含操作说明）
- CP210x USB 驱动 — 串口通信必要
- Icom USB Serial Port Driver — Icom 专用 USB 驱动
