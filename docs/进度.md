### CivCtrl.dll — CI-V 协议核心 ✅

**大小:** 148 KB | **导出:** 18 函数 | **编译器:** Borland C++ (MSVC 5.0)

核心发现：
- **CI-V 帧运行时构造** — 静态二进制零个完整 CI-V 帧模板，civSendSub 用循环写 (preambleCount+2) 个 0xFE，memcpy 命令体，尾部写 0xFD
- **Mailslot IPC** — civSend 不直接打串口，写 `\\.\mailslot\civsend`，由内部 SendRecvThread 读后写串口
- **CIVDriver 对象布局** — ~0xB00 字节，含 vtable、hCom、comPort、baudRate、toAddr(0x7F)、fromAddr(0x00)、preambleCount、civTot(15000)、status(IDLE=1)、TxBuf/RxBuf、临界区
- **状态机** — IDLE→ECHO_WAIT→ECHO_CHECK→ANSWER_WAIT→ANSWER_PROC→IDLE，ECHO/ANSWER 各 500ms 超时
- **串口配置** — `baud=%d parity=N data=8 stop=1`，默认 9600 8N1

详见: `phase2-re/notes/pe_analysis/CivCtrl_deep_analysis.md`

### UtyCtrl.dll — 控制层 ✅

**大小:** 200 KB | **导出:** 9 函数 | **编译器:** MSVC 9.0 + MFC

核心发现：
- **Mailslot IPC（非 WLAN socket）** — UtyCtrl.dll 不导入 ws2_32.dll，通过 Windows Mailslot 与本机 RemoteUtility 进程通信
- **数据流修正** — RemoteController.exe → UtyCtrl.dll ──Mailslot──► RemoteUtility.exe ──WLAN──► 远端
- **命令协议** — `{cmd_code:1, data_len:1, reserved:2, payload[data_len]}`，9 个命令码全部映射
- **致命漏洞** — 0x10001145 轮询循环无超时上限，RemoteUtility 崩溃导致 UtyCtrl 线程永久挂死
- **安全缺陷** — Mailslot 无认证，本机任意进程可注入/抢占/窃听

详见: `phase2-re/notes/pe_analysis/UtyCtrl_deep_analysis.md`

### RadioSch.dll + RemoteUty.exe — 硬件层 + 网络层 ✅

**RadioSch.dll:** 1.97 MB | 5 导出 | **RemoteUty.exe:** 3 MB | 20 DLL 导入

核心发现：
- **纯 UDP 通信** — `socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP)`，无 TCP
- **端口配置** — 从注册表 `SOFTWARE\Icom\Remote Utility` 读取 CommandPort/SerialPort/AudioPort（默认 50001/50002/50003）
- **自研可靠 UDP 栈** — CUdp → CUDPCtrl（会话）→ CUDPCtrl2（重传+同步+心跳）
- **USB HID 发现** — SETUPAPI 9 函数 23 调用点，`VIDPID%d` 模板匹配设备 ID
- **虚拟驱动** — icom_vaudio.sys + icom_vserial.sys，通过 `\\.\ICOM_SERIAL` 打开
- **安全** — UDP 明文无加密无认证，无 SO_REUSEADDR

详见: `phase2-re/notes/pe_analysis/RadioSch_RemoteUty_deep_analysis.md`

### MCP 接口层封装 ✅ (2026-08-11)

把 CI-V 控制能力封装成 MCP (Model Context Protocol) 接口，供外置 MCP 客户端（陆墨）远程控制电台。

**依赖底座**：`CivViaExecCmdSender`（Mailslot ExecCmd 桥接，见 `src/rsba1/mailslot/civ_via_execcmd.py`）——写 `RemoteUtyCtrlCmd`，让 RemoteUty 把 CI-V 命令转发到电台，无需 RemoteController/UtyCtrl/CivCtrl。

**模块**：`src/rsba1/mcp/`
- `server.py` — FastMCP 服务 + 6 个 tool
- `__main__.py` — 服务入口（stdio/sse）
- `__init__.py` — 惰性导入封装

**tool 清单**：

| tool | 类型 | 说明 |
|------|------|------|
| `read_freq` | 闭环查询 | 读 VFO 频率 (Hz) |
| `read_mode` | 闭环查询 | 读模式 + filter |
| `read_smeter` | 闭环查询 | 读 S-meter 原始值 |
| `set_freq` | fire-and-forget | 设频率（业余频段白名单校验） |
| `ptt` | fire-and-forget | 控制 PTT (TX/RX) |
| `get_status` | 组合查询 | 频率+模式+S-meter 一站式 |

**验证状态**：
- ✅ mock 冒烟测试（`tools/mcp/mcp_smoke_test.py`）：6 tool 注册齐全、调用正确、白名单越界拦截
- ✅ stdio 协议实测：`initialize` + `tools/list` 返回全部 6 tool，`serverInfo=ic705-rsba1`
- ⬜ 真机桥接闭环（需 RemoteUty 运行 + 电台响应 + RemoteController 关闭）

**启动方式**：
```
python -m rsba1.mcp                      # stdio（默认，供 MCP 客户端子进程发现）
python -m rsba1.mcp --transport sse --port 8765   # HTTP SSE
```

**依赖**：fastmcp 3.4.7（惰性导入，未安装时仅导入模块不报错）。

物理前置条件（桥接闭环）：RemoteUty.exe 运行中；read_* 闭环查询要求 RemoteController.exe 未运行（否则占用响应 mailslot）。
